Backups, roll back, a new world, and how the server is doing.

The admin page is off. To turn it on, set LETOPIS_ADMIN_TOKEN on the container (in Unraid: edit the container, Add another Path, Port, Variable, a Variable with that key and a long password as its value), then restart it.

Rolling back puts the world back as it was in that backup and removes from the chronicle, the family records and the statistics everything written after it. The running totals of what happened most and the all-time records keep counting. A backup of the world as it is now is taken first, so a roll back can itself be undone.

A new world

The current world is backed up and archived (as when a world dies out), and a new one begins at once, 12,000 BC. The same seed always makes the same land.
